# E-Commerce Sales and Profitability Analysis

## Project Overview

This is an end-to-end data analytics project focused on analyzing e-commerce sales, customer behavior, product performance, revenue, and profitability.

The project follows a complete analytics workflow using Excel, SQL Server, Python, and Power BI, starting from data preparation and ending with business insights and recommendations.

---

## Project Objective

The objective of this project is to analyze e-commerce business data and answer important business questions related to:

- Revenue and profit performance
- Order and customer activity
- Product performance
- Customer contribution
- Geographic performance
- Payment methods
- Sales and profit trends
- Discount and profitability relationships

---

# Project Explanation Using STAR Method

## 1. Situation

The e-commerce business had customer, order, and product data containing information about transactions, sales, costs, discounts, customers, and products.

However, the raw data did not provide a clear and consolidated view of business performance.

The business needed a data-driven approach to understand sales, profitability, customer contribution, product performance, and operational trends.

---

## 2. Task

The goal of the project was to transform the raw e-commerce data into meaningful business insights.

The main tasks were:

- Clean and validate the datasets
- Analyze the data using Excel
- Perform business analysis using SQL Server
- Conduct exploratory data analysis using Python
- Build an interactive Power BI dashboard
- Identify key business trends and relationships
- Provide actionable recommendations

---

## 3. Action

### Data Preparation and Cleaning

I inspected and cleaned the datasets by checking:

- Missing values
- Duplicate records
- Data types
- Data consistency
- Relationships between Customers, Orders, and Products

Date fields were converted into appropriate formats and additional date features were created for trend analysis.

### Excel Analysis

Excel was used for:

- Initial data inspection
- Data cleaning
- Data validation
- Lookup operations
- Calculations
- Preliminary analysis

### SQL Server Analysis

The datasets were imported into SQL Server and analyzed using SQL queries.

The SQL analysis included:

- Total orders
- Total customers
- Total revenue
- Total profit
- Average order value
- Revenue and profit by product category
- Top 10 products by revenue
- Top 10 customers by revenue
- Revenue and profit by city
- Table and data validation

SQL techniques used included:

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOIN
- INNER JOIN
- UNION ALL
- COUNT
- COUNT DISTINCT
- SUM
- AVG
- TOP

### Python Exploratory Data Analysis

Python was used to perform exploratory data analysis.

Libraries used:

- Pandas
- NumPy
- Matplotlib
- Seaborn

The analysis included:

- Dataset overview
- Data type analysis
- Missing-value analysis
- Duplicate analysis
- Data cleaning
- Monthly revenue trends
- Monthly profit trends
- Payment method analysis
- Order status analysis
- Average order value
- Correlation analysis

Visualizations included:

- Bar charts
- Line charts
- Correlation heatmaps

### Power BI Dashboard

An interactive five-page Power BI dashboard was developed to present the results.

The dashboard includes:

1. Executive Overview
2. Sales Analysis
3. Product Analysis
4. Customer Analysis
5. Key Business Insights

Power BI features used:

- Data modeling
- DAX measures
- KPI cards
- Slicers
- Charts

- Page navigation
- Interactive dashboard elements

---

## 4. Result

The project transformed raw e-commerce data into a complete business intelligence solution.

The final analysis provides insights into:

- Overall sales and profitability
- Customer contribution
- Product performance
- Geographic performance
- Payment behavior
- Order status
- Monthly revenue and profit trends
- Relationships between sales, costs, discounts, and profit

The analysis also identified a strong positive relationship between Net Sales and Profit, while higher discount percentages showed a negative relationship with Profit Margin in the analyzed dataset.

These findings were used to develop business recommendations and support the final Power BI dashboard.

# Business Recommendations

Based on the analysis, the business can consider:

1. Monitor discount levels to protect profit margins.
2. Focus on high-performing products and categories.
3. Identify and retain high-value customers.
4. Investigate low-performing geographic markets.
5. Monitor monthly revenue and profit trends.
6. Track order status to identify operational issues.
7. Use customer and product performance data to improve sales strategies.
